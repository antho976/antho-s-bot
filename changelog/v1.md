# v1 — Phase 1: Stream Notifications

_2026-06-02_

The bot's core purpose: Twitch & YouTube alerts. This release ships the **full alert engine and
dashboard** — you can watch channels, configure alerts, schedule streams, and fire test alerts
into Discord. The real Twitch/YouTube auto-detection is scaffolded and ready, pending API keys.

## Added

### Notification engine
- Watch **Twitch / YouTube** channels (`platform` discriminator) with per-channel alert settings:
  target Discord channel, ping role, embed on/off, per-event toggles (live / end / upload), and a
  custom message template (`{name} {platform} {title} {game} {url}`).
- Alert formatter builds the embed or plain message; Discord dispatch posts it (with role ping).
- **Fake live / end / upload** test triggers — preview a real alert in Discord without streaming.
- Events recorded (`stream_events`) and tracked via `track()` (`stream.live/end/upload`).

### Schedule & reminders
- Ad-hoc **upcoming streams**: set a date/time per stream with 1h / 10min reminder toggles.
- In-process **scheduler** (minute tick) fires due reminders to the channel's Discord target,
  marking each sent so it can't repeat.

### Maintenance (Overview)
- **Reset live state**, **Reset schedule**, **Reset daily stats** — each audit-logged.

### Platform seam (ready, inert until creds)
- `StreamProvider` interface; **Twitch (EventSub)** + **YouTube (PubSubHubbub)** provider scaffolds.
- Webhook routes `/api/webhooks/twitch` and `/api/webhooks/youtube` — signature/challenge
  handshakes implemented; dispatch path wired. `subscribe()`/`parse()` get filled in with API keys.

### Data & API
- Tables: `stream_channels`, `stream_state`, `stream_events`, `stream_schedule` (migration `0001`).
- Routes: notifications channels CRUD, schedule CRUD, test trigger, maintenance, webhooks.
- Dashboard: **Notifications** page (channels + schedule) added to the nav.
- `env`: optional `TWITCH_*` / `YOUTUBE_API_KEY` added.
