# v2 — Phase 2: Welcome & Leveling

_2026-06-02_

Two community features, logic-first and fully configurable from the dashboard. (Polish — richer
visuals, uploads, etc. — is deferred to `planning/10-polish-backlog.md`.)

## Added — Leveling
- **XP** from messages (15–25, 60s cooldown), **voice** (5/min, skips muted/AFK members), and
  **reactions** (off by default) — every value configurable.
- **Curve:** multiplier formula (configurable base + factor) with a custom-per-level table ready;
  **prestige** tracked.
- **Level-ups** announce in chat and **grant role rewards** automatically.
- **Dashboard → Leveling:** leaderboard (top 25, names from cache), full settings, role-reward manager.
- Tables: `levels`, `level_config`, `level_rewards`, `level_curve` (migration `0002`). `track()`: `level.up`.

## Added — Welcome & Goodbye
- **Welcome + goodbye** messages with modes **text / image / both**.
- **Custom artwork** (avatar + name on a gradient or background image) rendered with `@napi-rs/canvas`.
- Template placeholders `{user} {username} {server} {memberCount}`.
- **Backgrounds** by URL with optional **random pick** each time.
- **Dashboard → Welcome:** welcome/goodbye settings, backgrounds manager, and a **live preview**
  (renders a sample card with your avatar + current settings).
- Tables: `welcome_config`, `welcome_backgrounds` (migration `0003`). `track()`: `welcome.join`, `welcome.leave`.

## Infrastructure
- The in-process scheduler now also runs the **voice-XP tick**.
- `@napi-rs/canvas` added as a server-external native package.
- Feature event wiring (leveling + welcome gateway handlers) registered on boot.

## Changed
- Nav: **Leveling** and **Welcome** added.
