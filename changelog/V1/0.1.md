# 0.1 — Stream Notifications (core)

_2026-06-02 · commit `731e3d6`_

The bot's core purpose: the Twitch/YouTube alert engine + dashboard.

## Added
- Watch **Twitch / YouTube** channels with per-channel alert settings: target Discord channel,
  ping role, embed on/off, per-event toggles (live / end / upload), custom message template
  (`{name} {platform} {title} {game} {url}`).
- Alert **formatter** (embed or plain) → **Discord dispatch** with role ping.
- **Fake live / end / upload** test triggers — preview a real alert without streaming.
- Events recorded; `track()`: `stream.live/end/upload`.
- **Dashboard → Notifications:** add/edit/delete channels, configure alerts, fire tests.
- Tables: `stream_channels`, `stream_state`, `stream_events` (migration `0001_notifications`).

## Verified
- `tsc` clean · `next build` clean.

# 0.1.1 — Notifications: schedule, maintenance, provider scaffolds

_2026-06-02 · commit `bb9d658`_

## Added
- **Schedule & reminders:** ad-hoc upcoming streams with 1h / 10min reminder toggles; an
  in-process **scheduler** (`src/server/core/scheduler.ts`) fires due reminders (no double-send).
- **Maintenance** (Overview): reset live / reset schedule / reset daily — audit-logged.
- **Platform seam:** `StreamProvider` interface; **Twitch (EventSub)** + **YouTube (PubSubHubbub)**
  provider scaffolds + webhook routes `/api/webhooks/twitch|youtube` (verification handshakes
  implemented; inert until API credentials are added).
- `env`: optional `TWITCH_*` / `YOUTUBE_API_KEY`; documented `AUTH_URL` for Render.

## Notes

# 0.1.2 — Leveling

_2026-06-03 · commit `cd7ca39`_

## Added
- **XP** from messages (15–25, 60s cooldown), **voice** (5/min, skips muted/AFK), and
  **reactions** (off by default) — all configurable.
- **Curve:** multiplier formula (configurable base + factor) with a custom-per-level table ready;
  **prestige** tracked.
- **Level-ups** announce in chat and **grant role rewards** automatically.
- **Dashboard → Leveling:** leaderboard (top 25), full settings, role-reward manager.
- Tables: `levels`, `level_config`, `level_rewards`, `level_curve` (migration `0002_leveling`).
  `track()`: `level.up`.

## Verified
