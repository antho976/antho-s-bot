# 0.1 — Stream Notifications (core)

_2026-06-02 · commit `731e3d6`_

The bot's core purpose: the Twitch/YouTube alert engine + dashboard.

## Added
- Watch **Twitch / YouTube** channels with per-channel alert settings: target Discord channel,
  ping role, embed on/off, per-event toggles (live / end / upload), custom message template
  (`{name} {platform} {title} {game} {url}`).
- Alert **formatter** (embed or plain) → **Discord dispatch** with role ping.
- **Fake live / end / upload** test triggers — preview a real alert without streaming.
- Events recorded; `track()`: `stream.live/end/upload`.
- **Dashboard → Notifications:** add/edit/delete channels, configure alerts, fire tests.
- Tables: `stream_channels`, `stream_state`, `stream_events` (migration `0001_notifications`).

# 0.1.4 — Member Logs & Scam Auto-mod

_2026-06-03 · commit `8e2e234`_

## Added
- **Member Logs:** log joins / leaves / bans / unbans / nickname & role changes / message edits
  & deletes / voice activity — each toggleable, to one channel, with a dashboard config + a
  recent-activity feed. Added the `GuildModeration` intent (for ban events).
  Tables: `member_log_config`, `member_events` (migration `0004_member_logs`).
- **Auto-mod (scam protection):** deliberately *not* a copy of Discord's native automod — only
  the scam gap. Detects lookalike domains (discord/steam typosquats), "free nitro" + link
  phrases, and a custom scam-domain blocklist. Actions: delete + timeout + log; staff exempt;
  recent-actions feed. Tables: `automod_config`, `automod_blocklist`, `automod_actions`
  (migration `0005_automod`). `track()`: `memberlog.*`, `automod.scam`.

## Verified
- `tsc` clean · `next build` clean.
